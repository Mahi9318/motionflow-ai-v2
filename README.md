# MotionFlow AI

Kling Motion Control style web app using the Kling V3 Motion Control API through fal.ai.

## Vercel setup
1. Import this GitHub repository into Vercel.
2. Open Project Settings -> Environment Variables.
3. Add `FAL_KEY` with your fal.ai API key.
4. Select Production, Preview and Development.
5. Redeploy.

Never put `FAL_KEY` in frontend files.
